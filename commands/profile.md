执行主页脚本($1 可选,是他人主页链接;不填则看用户自己的主页):

```
cd ${CLAUDE_PLUGIN_ROOT} && node scripts/profile.mjs ${1:+--url "$1"}
```

拿到 JSON 后整理成两部分回复:

1. **账号概况**:昵称、抖音号、粉丝/关注/获赞/作品数,一句话点评账号体量。
2. **作品表现**:列出作品(发布日期、文案、点赞/评论/分享),按点赞排序,指出表现最好和最差的作品,并分析规律(什么题材/文案数据好),给 1-2 条下次发什么的建议。

如果报未登录,提示用户先运行 `/douyin:login`。
